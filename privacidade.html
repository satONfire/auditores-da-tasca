Política de Privacidade

1. Quem somos

O website Auditores da Tasca é um projeto recreativo dedicado à divulgação humorística de avaliações gastronómicas e culturais de tascas e estabelecimentos similares.

2. Dados pessoais

Este website não recolhe dados pessoais dos visitantes, não exige registo e não cria contas de utilizador.

3. Formulários

Caso venha a existir um formulário de contacto, os dados fornecidos serão utilizados exclusivamente para responder ao pedido efetuado.

4. Conservação dos dados

Os dados eventualmente enviados através de formulários serão conservados apenas pelo tempo necessário ao tratamento do pedido.

5. Direitos do utilizador

Nos termos do Regulamento Geral sobre a Proteção de Dados (RGPD), qualquer utilizador poderá solicitar acesso, retificação ou eliminação dos seus dados pessoais.

6. Contacto

Para qualquer questão relacionada com a privacidade poderá contactar os responsáveis pelo projeto.
